02 / TIME IS A CONSTRAINT

Train. Select. Calibrate. Then test.

NO RANDOM TIME SPLITS

What a forecast knows

A completed 10-second bar and its past five minutes: returns, volatility, trade volume, count, taker imbalance and staleness. No quotes or order-book depth are available.

What it predicts

The next 60-second last-trade-price log return: down below −3 bps, up above +3 bps, otherwise flat. Labels crossing the UTC day boundary are excluded.

How it scales

Compressed archives are read row by row. The linear model trains in 4,096-row batches. Boosted trees use the compact feature matrix in memory.

04 / MONITORING

Watch the data move.

Per-test-day population stability index (PSI), using training quantile bins. A value above 0.2 is an illustrative review flag, not a statistical alarm or a model failure diagnosis. Computed after the day ends.

05 / WHY THIS PROJECT

Built around a research workflow.

This independent portfolio project targets the dataset preparation, time-series benchmarking and calibration work described in Alipes’ Machine Learning Researcher role.

It demonstrates the workflow on accessible crypto records. Equities deployment would require licensed venue data, market-session handling, quote-aware labels and much broader validation.
